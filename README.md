# webalator-assets

Public image assets for Webalator demo sites, served via GitHub Pages.

Stable URLs: `https://drofoneseller.github.io/webalator-assets/<site>/<name>.jpg`

To update an image, replace the file (same name) and push — live sites pick it up with no republish.
