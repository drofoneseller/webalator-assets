# webalator-assets

Public image assets for Webalator demo sites.

**Preferred CDN:** `https://cdn.jsdelivr.net/gh/drofoneseller/webalator-assets@main/<site>/<name>.jpg`  
Also: `https://drofoneseller.github.io/webalator-assets/<site>/<name>.jpg`

To update an image, replace the file (same name) and push — live sites pick it up with no republish (jsDelivr may cache briefly).
